# ShoeTown 👟

ShoeTown là một website bán giày trực tuyến được xây dựng bằng Java Servlet/JSP. Người dùng có thể đăng ký, đăng nhập, duyệt danh sách sản phẩm, thêm vào giỏ hàng và thực hiện đặt hàng.

## 🌟 Tính năng chính:
- Đăng nhập / đăng ký người dùng
- Danh sách sản phẩm giày với hình ảnh, mô tả, giá
- Thêm/sửa/xoá sản phẩm trong giỏ hàng
- Xử lý đơn hàng
- Phân quyền: admin và user

## 🛠️ Công nghệ sử dụng:
- Java Servlet & JSP
- JSTL & EL
- SQL Server
- JDBC
- HTML/CSS

## 📁 Cấu trúc project:
- `controller`: các servlet xử lý logic
- `model`: DTO, DAO, DBUtils
- `view`: các trang JSP
